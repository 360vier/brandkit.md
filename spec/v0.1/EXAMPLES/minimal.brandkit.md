# brand overview
- display_name: Northstar Labs
- short_name: Northstar

## mission and positioning
- mission: Make technical decisions understandable.
- positioning: Practical guidance for engineering teams.

## audience
- primary_segments:
  - Engineering leads
  - Product managers

## voice and tone
- tone_attributes:
  - clear
  - calm
  - direct
- avoid_patterns:
  - hype claims
  - vague slogans

## messaging
- core_message: We turn complexity into shippable technical direction.
- proof_points:
  - Published migration guides used by partner teams
  - Clear implementation checklists in every release

## brand expressions
- fallback_wordmark: NORTHSTAR
- plain_text_signature: [NORTHSTAR]
- ascii_mark: |
    /\
   /  \
  /_/\_\
- text_only_identity_rules:
  - Prefer NORTHSTAR in all-caps for plain text headers.
  - Keep signatures short in terminal contexts.

## do and dont
- do:
  - Use concise, instructional language.
  - Prefer explicit next steps.
- dont:
  - Use abstract mission statements without actions.
  - Use decorative symbols in dense paragraphs.

## usage notes for ai systems
- allowed_contexts:
  - technical memos
  - migration notes
- restricted_contexts:
  - legal statements without human review
- fallback_behavior: If uncertain, use plain_text_signature and neutral tone.
