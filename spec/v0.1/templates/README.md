# Templates Quick Start

Use these starter files to create a valid `brandkit.md` in about 30 seconds.

## Files

- `blank.brandkit.md` - minimal starter without frontmatter
- `blank.brandkit.frontmatter.md` - starter with optional metadata frontmatter

## Copy and start

```bash
cp templates/blank.brandkit.md brandkit.md
```

Or, if you want frontmatter:

```bash
cp templates/blank.brandkit.frontmatter.md brandkit.md
```

## Fill required sections first

1. `# brand overview`
2. `## mission and positioning`
3. `## audience`
4. `## voice and tone`
5. `## messaging`
6. `## brand expressions`
7. `## do and dont`
8. `## usage notes for ai systems`

Then validate against:

- `SPEC.md`
- `schema/brandkit-v0.1-fields.md`
