# Comparison and Boundaries

## Compared to traditional brand guidelines

- Brand guidelines: broad visual systems (logo spacing, typography, color definitions, campaign rules).
- `brandkit.md`: a text- and AI-oriented core for reproducible Markdown output.

## Compared to design systems

- Design systems: components, design tokens, UI implementation details.
- `brandkit.md`: linguistic and contextual brand guidance for documents and agent output.

## Compared to `llms.txt`

- `llms.txt`: primarily model discovery and navigation hints.
- `brandkit.md`: style and brand context used during content generation.

## Compared to `agents.md` or skill files

- `agents.md`/skills: behavioral instructions for agents.
- `brandkit.md`: brand-specific expression context those agents can apply while writing.

## Compared to prompt-only workflows

- Prompts are situational and ephemeral.
- `brandkit.md` is versionable, reviewable, and reusable across teams.

## Clear boundary

`brandkit.md` is not a full replacement for adjacent artifacts. It closes the gap between brand identity and AI-compatible Markdown production.
